# Документация Пульта 3.2

## Устройства

Устройство добавляется через «Добавить устройство» → сканирование QR-кода на корпусе. Устройство должно быть в одной сети Wi-Fi с телефоном.

## Журнал событий

Журнал показывает действия устройств и входы в аккаунт. Глубина журнала зависит от тарифа: Basic — 7 дней, Pro — 90 дней.

## Уведомления

Настройки → Уведомления. Можно выключить отдельные типы: двери, движение, температура.

## Синхронизация

Приложение синхронизируется с сервером при появлении сети. Если устройство показывает «не в сети», проверьте питание и Wi-Fi, затем потяните список вниз для обновления.
